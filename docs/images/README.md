# Images Directory

Place board images and documentation images here:

- `board.jpg` - ESP32-S3-POE-ETH-8DI-8DO board photo
- `pinout.jpg` - Board pinout diagram
- `schematic.jpg` - Electrical schematic (if available)
- `connection_diagram.jpg` - Typical connection setup
- `dimensions.jpg` - Board dimensions diagram

These images are referenced in README.md and examples.

## File Format Recommendations
- JPG: For photographs and complex diagrams (70-80% quality)
- PNG: For simple diagrams and logos (with transparency)
- SVG: For scalable vector diagrams
